# Dogma

First published: 2026/10/29

The title is a joke. To believe is to stop thinking. This is not an ideology but a list of my preferences.

## Things I dislike

- Bleeding-edge rolling-release Linux systems
- Not having options
- Commercialization
- Impenetrable monoliths
- Scattered systems riddled with obsolete parts and unclear structures
    - Dbus
    - X11
- Bloat and scope creep
    - Systemd (see [this](https://without-systemd.org/wiki/index_php/Arguments_against_systemd/) and [this](https://suckless.org/sucks/systemd/))
    - Gnu software, but I respect their impact in the world of FOSS and in bringing Linux into initial usability
    - Hyprland, Omarchy, and similar projects
- Languages that introduce new problems
    - C#
    - Java
    - To some extent, C++
    - JavaScript (yes, I am a hypocrite because my main site contains JS, but it's not functionally necessary. I specifically hate when I can't access sites from browsers like links)
- Dependency hell

## Things I like

- Avant-garde technology
- Neoluddism
- Contradiction, it seems!
- Modularity
- Simplicity
    - Musl
    - C
    - Suckless
    - RISC
    - Wayland, especially [wayland.fyi](https://wayland.fyi/)
- Sane OS dev
    - Unix
    - Plan 9 / 9front
    - OpenBSD
    - Lesser known non-Unix systems
- Sane Linux
    - Alpine Linux
    - Void Linux
    - Derive Linux
- Ironically, Debian
- Languages that interest me
    - Haskell
    - rc shell
    - Esoteric languages
- Retrocomputing
- Homebrew systems
- Free and open knowledge
- DIY ethos
