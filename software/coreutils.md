# Coreutils Clone

[Source Code](https://git.softmachine.dev/troyutils/)

Minimalist coreutils implementation in C. It contains only the functions that I actually use in each program, for better or for worse. In a way, it is inspired by Plan 9's implementations, which are much simpler than Gnu's. There are some serious issues with what I've done so far, some of which I have already fixed but not pushed yet.

## Aim

Essentially, this is an attempt to learn Unix programming. My knowledge of programming thus far was limited to the abstract foundations that I was taught. I had little real-world experience, and I hated that. I was particularly curious about how the most basic tools worked, so I took on this project. I learned a bit about relevant C libraries.
